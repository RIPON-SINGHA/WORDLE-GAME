# Wordle Game (Python + Tkinter)

A simple Wordle clone built using Python and Tkinter.

## Features
- GUI-based gameplay
- On-screen keyboard
- Input validation
- Win/Lose popup
- Packaged as .exe

## How to Run
Download the `.exe` from the `dist/` folder and run it. i have also release the version of it.
